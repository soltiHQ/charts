{{- $mode := include "podium.mode" . -}}
podium {{ include "podium.imageTag" . }} runs in {{ $mode }} mode as the Deployment {{ include "podium.fullname" . }} in {{ .Release.Namespace }}{{ if eq $mode "database" }}, {{ .Values.replicas }} replicas{{ end }}.

Web UI and API:
{{- if .Values.ingress.enabled }}
{{- range .Values.ingress.hosts }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}
{{- else }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "podium.fullname" . }} 8080:{{ .Values.service.port }}
  then open http://127.0.0.1:8080
{{- end }}

First administrator: user admin.
{{- if eq $mode "database" }}
  Its password is the Secret's {{ .Values.secrets.keys.bootstrapAdminPassword }} key. An empty database needs it:
  without it the replicas stop at start. Change the password after the first login, then remove that key
  and restart the Deployment: podium warns about it at each start while users exist.
{{- else if or .Values.secrets.bootstrapAdminPassword .Values.secrets.existingSecret }}
  Its password is the Secret's {{ .Values.secrets.keys.bootstrapAdminPassword }} key, when set.
{{- else }}
  No bootstrap password was given, so podium generated one and logged it once, at WARN, at each start:
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "podium.fullname" . }} | grep "admin password generated"
{{- end }}

Agents reach the {{ include "podium.fullname" . }}-agents Service ({{ .Values.agents.service.type }}):
  HTTP discovery on {{ .Values.agents.service.discoveryPort }}, gRPC on {{ .Values.agents.service.grpcPort }}.
{{- if eq .Values.agents.service.type "ClusterIP" }}
  It is reachable from inside the cluster only: agents outside it need agents.service.type LoadBalancer or NodePort.
{{- end }}
{{- if or .Values.secrets.enrollSecret .Values.secrets.existingSecret }}
  An agent's token, derived from the enrollment secret:
  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "podium.fullname" . }} -- /podium agent-token <agent-id>
{{- else }}
  WARNING: no enrollment secret: any host that reaches these ports can enroll a new agent ID.
{{- end }}
{{- if .Values.tls.server.secretName }}
  The listeners serve TLS with the certificate of the Secret {{ .Values.tls.server.secretName }}{{ if .Values.tls.server.clientCA.secretName }}, and the agents' listeners require a client certificate{{ end }}.
{{- else }}
  The listeners serve plaintext: the SDK sends an agent's token only over TLS, unless the agent allows
  insecure token transport. Set tls.server.secretName for TLS.
{{- end }}
  podium calls each agent at the endpoint it registers, so the agents' endpoints must be reachable from the pods.

{{- if eq $mode "memory" }}

The state lives in memory and is lost with the pod: every restart starts empty, and the users, specs,
agents and sessions are gone. For state that survives, use mode: database.
{{- else }}

The state lives in your Postgres database, which this chart neither runs nor backs up.
{{- if .Values.migrate.job.enabled }}
  The schema is migrated by the Job {{ include "podium.hookName" (dict "root" . "component" "migrate") }}, a hook before each install and upgrade.
{{- else }}
  Each replica migrates the schema at start, under a database lock.
{{- end }}
{{- if lt (int .Values.replicas) 2 }}
  WARNING: one replica: a restart of it leaves nothing to serve in the meantime.
{{- end }}
{{- if include "podium.dropSchemaOnUninstall" . }}
  WARNING: helm uninstall drops every table of podium's from the database, and all of its data, once
  the replicas stopped (dropSchema.onUninstall). There is no undo: back the database up first.
{{- end }}
{{- if not .Values.tls.server.secretName }}
  WARNING: without tls.server the replicas forward each other's writes, logins, cookies and tokens
  included, in plaintext.
{{- end }}
{{- end }}

Upgrading from chart 0.0.1: it ran a StatefulSet with a PersistentVolumeClaim. This chart replaces the
StatefulSet with a Deployment and leaves the claim in place, unused: once you no longer need the state
in it, delete it yourself (kubectl -n {{ .Release.Namespace }} delete pvc data-{{ include "podium.fullname" . }}-0).
